LOGO SETUP INSTRUCTIONS
=======================

You provided two KBP logo images with gradient backgrounds (pink-orange and orange).

To use your logo on the website:

1. Save one of your logo images as "logo.png" in this directory
   (the same folder as index.html)

2. Recommended: Use the pink-orange gradient version as it matches 
   the futuristic color scheme better

3. If your logo has a background, consider using a version with a 
   transparent background for better integration with the dark theme

4. The logo will automatically appear on all three pages with a 
   glowing effect

Alternative: If you want to use the logo directly without saving:
- Rename your logo file to "logo.png" 
- Place it in the root directory alongside the HTML files

The website is designed to work with PNG, JPG, or SVG logo formats.
